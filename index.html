01 · Introducción

¿Para qué estudiamos engranajes?

Los engranajes son elementos de máquinas usados para transmitir fuerza y movimiento entre ejes que se encuentran a poca distancia. Generalmente se identifica como rueda a la de mayor tamaño y como piñón al más pequeño.

Los manuales también destacan que el desgaste o daño de un engranaje puede requerir medirlo y bosquejarlo para posteriormente elaborar su dibujo técnico.

05 · Módulo y dimensiones

El módulo

El módulo se obtiene dividiendo el diámetro primitivo entre el número de dientes:

M = Dp / z

También aparecen en el manual el paso circular, el espesor circular, la altura de cabeza, el juego, la altura total del diente y otras dimensiones.

Paso circular
Pe = 3.1416·Dp / z
Espesor circular

Es la mitad del paso circular.

Altura de cabeza
h1 = M
Juego
J = 1/20 Pe = 0.157M

Actividad · Completa

Si Dp = 147 mm y z = 21, ¿cuál es el módulo?

Recuerda las fórmulas: M = Dp / z; Pe = 3.1416 × Dp / z; espesor circular = Pe / 2; h1 = M; J = Pe / 20 = 0.157M.
06 · Mini práctica

Dimensiones del diente

El manual indica que la altura total del diente es aproximadamente 2.157M, y que el diámetro interior se expresa como Di = Dp − 3.314M.

Verdadero o falso

La altura de cabeza h1 es igual al módulo M.

Otro reto

Si M = 7 mm, ¿cuánto vale h1?

Recuerda las fórmulas: Altura de cabeza h1 = M; altura total del diente h = 2.157M; diámetro interior Di = Dp − 3.314M.
07 · Cálculo del piñón

Ejemplo del manual

Para un piñón con z = 21 y M = 7, el diámetro primitivo es:

Dp = M·z = 7·21 = 147 mm

El ejemplo continúa con h1 = 7 mm, De = 161 mm, Pe ≈ 21.99 mm, espesor ≈ 10.995 mm, J ≈ 1.099 mm y Di ≈ 130.802 mm.

09 · Dibujo de taller

Del cálculo al dibujo

El dibujo de taller reúne los datos necesarios para representar el engranaje. El manual también presenta el sistema de paso diametral usado en el sistema ANSI:

Pd = z / Dp (en pulgadas)
Dp = z / Pd
M = 25.4 / Pd

Actividad · Verdadero o falso

En el sistema de paso diametral, Pd = z/Dp cuando Dp está expresado en pulgadas.

10 · Puente a helicoidales

Engranajes helicoidales

Los dientes de un engranaje helicoidal se tallan en ángulo respecto al eje. Pueden utilizarse entre ejes paralelos o entre ejes que se cruzan; el ángulo de 90° es común.

Cuando los ejes son paralelos, los ángulos de talla son iguales, pero una rueda se talla hacia la izquierda y la otra hacia la derecha.

Módulo normal y aparente

Ma = M / cos α
M = Ma·cos α
Pa = Pr / cos α
Pr = 3.1416M

12 · Cálculo helicoidal

Ejemplo del manual

Dp rueda ≈ 124.24 mm
Dp piñón ≈ 62.12 mm
De rueda ≈ 130.24 mm

El centro aproximado del ejemplo es 93.18 mm y la relación de transmisión es 20/40 = 1/2.

Actividad · Cálculo

Si M = 4 mm, z = 30 y α = 0°, usando cos 0° = 1, ¿cuál es Ma?

Recuerda las fórmulas: Módulo aparente Ma = M / cos α. Si α = 0°, cos 0° = 1 y por tanto Ma = M / 1.

Ángulo de presión y línea de presión

En el manual de engranajes cilíndricos rectos, el ángulo de presión es el ángulo de inclinación con que la rueda conductora impulsa los dientes de la inducida. El manual menciona 20° y 14° 1/2°.

Línea de presión

Flanco

16 · Dimensiones

Más dimensiones del engranaje recto

Además de los diámetros principales, el manual presenta tres relaciones útiles para dimensionar un engranaje recto: el ancho de cara, el espesor mínimo del aro y el juego.

1. Ancho de cara (F)

F = 6M a 10M

Significa: el ancho de cara debe estar entre 6 y 10 veces el módulo.

Ejemplo con M = 7 mm:

F mínimo = 6 × 7 = 42 mm
F máximo = 10 × 7 = 70 mm

2. Espesor mínimo del aro

e mínimo = 1.5M

Esta relación se usa cuando la rueda está ahuecada.

Ejemplo con M = 7 mm:

e mínimo = 1.5 × 7 = 10.5 mm

3. Juego (J)

J = Pe / 20
J = 0.157M

El manual presenta estas dos expresiones para el juego.

Ejemplo con M = 7 mm:

J = 0.157 × 7 ≈ 1.10 mm

Actividad · Cálculo paso a paso

Datos: módulo M = 7 mm. Elige el cálculo del ancho de cara cuando se utiliza 8M.

Paso 1. Escribe la relación:

F = 8M

Paso 2. Sustituye M = 7 mm:

F = 8 × 7

Paso 3. Calcula el resultado:

F = 56 mm

¿Cuál es el ancho de cara correcto para 8M?

Recuerda las fórmulas: Ancho de cara F = 6M a 10M; espesor mínimo del aro e = 1.5M si la rueda es ahuecada; juego J = Pe / 20 = 0.157M. Para M = 7 mm, sustituye el valor en cada fórmula.

18 · Sistema ANSI

Paso diametral

El manual de engranajes cilíndricos rectos también presenta el sistema de paso diametral (ANSI), que utiliza el diámetro primitivo expresado en pulgadas.

Pd = z / Dp
Dp = z / Pd
M = 25.4 / Pd
Pd = 25.4 / M

Actividad · Calcula el paso diametral

Datos: módulo M = 5.08 mm. Debes calcular el paso diametral (Pd) usando la equivalencia que presenta el manual.

Paso 1. Escribe la fórmula:

Pd = 25.4 / M

Paso 2. Sustituye el módulo por 5.08:

Pd = 25.4 / 5.08

Paso 3. Divide:

Pd = 5

Ahora responde: ¿qué valor de Pd obtienes?

Recuerda: utiliza Pd = 25.4 / M. Introduce el resultado numérico, sin escribir la unidad.

Recuerda las fórmulas: Pd = z / Dp (con Dp en pulgadas); Dp = z / Pd; M = 25.4 / Pd; Pd = 25.4 / M. Para el ejercicio, usa Pd = 25.4 / 5.08.
19 · Helicoidales

Paso normal y paso aparente

El manual distingue el paso normal o real (Pr), medido perpendicularmente a la hélice, y el paso aparente (Pa), medido según una circunferencia primitiva paralela a la cara lateral.

Pr

Pr = Pa·cos α = 3.1416M

Pa

Pa = Pr/cos α

Ma

Ma = M/cos α

Actividad · Verdadero o falso

20 · Sentido de la hélice

Ejes paralelos y perpendiculares

Para ejes paralelos, los ángulos de talla son iguales, pero una rueda se talla hacia la derecha y la otra hacia la izquierda. Para ejes perpendiculares, los ángulos son complementarios.

Pequeña velocidad

α = 10°

Elevada velocidad

α = 30°

Gran velocidad

α = 45°

Fórmulas de referencia

Engranajes rectos

  • Módulo: M = Dp / z
  • Diámetro primitivo: Dp = M × z
  • Paso circular: Pe = 3.1416 × Dp / z
  • Paso diametral ANSI: Pd = z / Dp, usando Dp en pulgadas.
  • Conversión entre módulo y paso diametral: M = 25.4 / Pd y Pd = 25.4 / M.

Engranajes helicoidales

  • Módulo aparente: Ma = M / cos α
  • Diámetro primitivo: Dp = z × Ma
  • Diámetro exterior: De = Dp + 2M
  • En ejes paralelos, los ángulos de hélice son iguales y los sentidos de talla son opuestos.

Símbolos: Dp = diámetro primitivo; De = diámetro exterior; z = número de dientes; M = módulo; Ma = módulo aparente; α = ángulo de hélice; Pd = paso diametral. Usa la calculadora si la necesitas.
